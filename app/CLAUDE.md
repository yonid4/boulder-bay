# Boulder Bay — iOS app

- **The Xcode project is generated.** `project.yml` (XcodeGen) is the source of truth; `BoulderBay.xcodeproj` is gitignored. Add sources, targets, SPM packages and Info.plist keys to `project.yml`, then run `xcodegen generate`. Never hand-edit the `.xcodeproj`.
- **Views are covered by snapshot tests, view models by unit tests.** `GymPinView`, `SelectedGymCard` and `BestPickButton` have reference PNGs under `BoulderBayTests/Features/Map/__Snapshots__/`, `LogoChip` (what `LogoImage` draws) under `BoulderBayTests/DesignSystem/__Snapshots__/`, the side menu's `DrawerView` under `BoulderBayTests/Features/AppShell/__Snapshots__/`, `FirstPlaceView` under `BoulderBayTests/Features/Places/__Snapshots__/` (with `PlaceFormView`, `PlacesView` and `LocationChip`), the Gyms screen under `BoulderBayTests/Features/Gyms/__Snapshots__/`, the Rankings screen under `BoulderBayTests/Features/Rankings/__Snapshots__/`, `GymDetailContent` under `BoulderBayTests/Features/GymDetail/__Snapshots__/`, and the gate's `AccountLoadFailedView` under `BoulderBayTests/App/__Snapshots__/`. A deliberate visual change means re-recording: delete the affected PNGs, run the tests twice (the first run records and fails), and look at the new images before committing. Never re-record to silence a failure you haven't looked at. `MapView` itself isn't snapshot-tested — MapKit tiles don't render in snapshots. PNG names must be unique across the test target, because Xcode copies them flat into the bundle: a duplicate test name in another suite fails the build.
